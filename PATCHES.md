# Реестр патчей

Что переопределено, в каком чужом моде и на какой его версии. Разделы верхнего уровня — по патчируемому моду: в шапке раздела его идентичность и откуда брать исходники, дальше по подразделу на каждую переопределённую запись. Строка живёт, пока патч нужен; когда апстрим чинит вопрос сам — патч удаляется, а подраздел уезжает в «Снятые».

Проверка после апдейта чужого мода: взять запись из его свежей версии, сравнить с колонкой «Базис», убедиться, что переопределяемое поле не изменилось по смыслу. Если изменилось — патч переписывается, а не остаётся как есть: `using` наследует новую версию записи, но переопределённое поле останется вашим.

#### `BLADESONG` — лестница КД у Песни клинка

| | |
|---|---|
| Версия на момент патча | 4.11.22.2 (`main` @ `81a394a4`, 09.08.2026) |
| Файл | `Public/…/Stats/Generated/Data/Status_BOOST.txt` |
| Переопределено | только `Boosts` |
| Базис | `AC(1)` + шесть `IF(AbilityGreaterThan('Intelligence',N)):AC(1)` при N = 13, 15, 17, 19, 21, 23 |

**Зачем.** В базисе бонус равен модификатору Интеллекта, но лестница обрывается на 23 и выше замирает на +7, хотя характеристика идёт до 30. Патч продлевает ту же закономерность до потолка: 26 → +8, 28 → +9, 30 → +10.

Попутно семь независимых `AC(1)` свёрнуты во взаимоисключающие диапазоны `AC(1)…AC(10)`, из которых срабатывает ровно один. Суммы в перекрытом диапазоне не меняются, но в тултипе КД вместо семи строк «+1 от: Песнь клинка» остаётся одна. `AC()` не принимает выражение вместо числа: `ArmorClassBoostComponent.AC` — `int32`, в отличие от `Amount` у урона (`StatsExpressionParam`), поэтому лестница — единственная форма записи.

**Прочие поля наследуются**, включая `UnlockSpell(Shout_Bladesong_Dismiss)`, `RemoveConditions` и `OnRemoveFunctors` с очисткой `BLADESONG_BLADEWORK`. При апдейте мода проверять именно `Boosts`: если автор поменяет там что-то помимо лестницы (например, добавит новый буст), правка не доедет — её затрёт этот патч.

**История.** Предлагалось апстриму в PR #1110 и в [Discussion #1119](https://github.com/Yoonmoonsik/bg3dnd/discussions/1119); автор отказал — 23 он держит как потолок своего стола и предложил сделать патч-мод.
