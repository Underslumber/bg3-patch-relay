# BG3 Underslumber — Patch Relay

Приватный слой патчей поверх чужих модов Baldur's Gate 3. Мод ничего не добавляет от себя: он переопределяет отдельные записи других модов и обязан грузиться **последним** — в статах побеждает последняя загруженная запись с этим именем.

Что и зачем переопределено — в [PATCHES.md](PATCHES.md): разделы по патчируемым модам, в шапке каждого — ссылка на исходники мода, внутри подразделы по переопределённым записям. Этот реестр и есть смысл репозитория: без него через полгода непонятно, какой апдейт чужого мода что ломает.

## Устройство

```
Mods/PatchRelay_146ee64d-…/meta.lsx                     идентичность мода и зависимости
Public/PatchRelay_146ee64d-…/Stats/Generated/Data/*.txt переопределения статов
scripts/build-lslib.ps1                                 сборка .pak через LSLib + установка в игру
```

UUID мода — `146ee64d-4202-44ea-bd9a-87fbcc4aa36e`, каталог во всех ветках `PatchRelay_146ee64d-4202-44ea-bd9a-87fbcc4aa36e`.

## Как пишется патч

Мягкое переопределение — `new entry` плюс `using` с тем же именем: наследуется запись, загруженная раньше (чужая), и меняются только перечисленные поля.

```
new entry "BLADESONG"
type "StatusData"
data "StatusType" "BOOST"
using "BLADESONG"
data "Boosts" "…"
```

Без `using` запись создаётся с дефолтными полями и **затирает чужую целиком** — так делать только осознанно.

Переопределяется поле целиком, а не его часть: если в патче есть `Boosts`, всё содержимое `Boosts` из чужого мода замещается. Поэтому в патч копируются и те бусты, которые менять не собирались.

## Сборка и установка

```powershell
./scripts/build-lslib.ps1              # собирает PatchRelay.pak в корне репозитория
./scripts/build-lslib.ps1 -Install     # плюс кладёт его в папку модов игры
```

Имя скрипта называет тип сборки: `build-lslib.ps1` пакует через `Divine.exe` из LSLib и игры не требует; для официального Toolkit от Larian появится отдельный `build-toolkit.ps1`.

Путь к `Divine.exe` берётся из `$env:BG3_DIVINE`, иначе из соседнего репозитория `bg3-dnd55e-russian-localization/.tools/lslib`.

После установки — включить мод в менеджере и убедиться, что он стоит **ниже** всех патчируемых модов в порядке загрузки.

## Проверка после апдейта чужого мода

1. Взять свежую версию чужого мода — из репозитория исходников, указанного в шапке его раздела в `PATCHES.md`, либо распаковав `.pak`.
2. Сверить исходную запись с колонкой «Базис» в подразделе патча.
3. Совпало — патч жив; изменилось — переписать патч и обновить подраздел; починили у себя — удалить патч и перенести подраздел в «Снятые».
