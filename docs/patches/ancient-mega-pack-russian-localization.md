# Описания Ancient Mega Pack

| | |
|---|---|
| Мод | [Ancient Mega Pack](../patched-mods.md#ancient-mega-pack) |
| Версия на момент патча | 22.74.1.2 (`Version64` `803048110702985218`) |
| Файлы в Patch Relay | `Mods/…/Localization/{English,Russian}/AncientJewelry.loca.xml`, `Arcanizer.loca.xml`; русская реплика в `ExtraItems.loca.xml` |
| Файлы в чужом моде | Одноимённые файлы в `Mods/REL_Full_Ancient_…/Localization/{English,Russian}/` |
| Переопределённые строки | `h225…f7e7`, `h819…3ef0a`, `he90…f471`; русская `hbb1…8201` |
| Базис | `MAG_Neck25`, 40 RootTemplates оружия, инструкции станций и таблицы наград распылятора в Story |

Английское описание распылятора ошибочно требовало два артефакта и обещало одну порцию пыли. Story принимает один или несколько уникальных магических предметов снаряжения и выбирает случайные ресурсы по редкости каждого. Ошибочный русский override из предыдущего релиза снят.

UID оружейного описания назначен 40 вариантам десяти типов оружия, поэтому рассказ о конкретном трезубце заменён универсальным текстом в обоих языках. Для `MAG_Neck25` оставлено солнечное описание, соответствующее лучистой уязвимости и ослеплению; конфликтующее английское описание обычного астрального амулета перекрыто. Реплика Жатвы Темнейшего сохранена: её возможная ссылка находится в бинарных диалоговых данных, а не в текстовых stats.
