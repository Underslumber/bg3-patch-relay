# Русская локализация Ancient Mega Pack

| | |
|---|---|
| Мод | [Ancient Mega Pack](../patched-mods.md#ancient-mega-pack) |
| Версия на момент патча | 22.74.1.2 (`Version64` `803048110702985218`) |
| Файлы в Patch Relay | `Mods/…/Localization/Russian/AncientJewelry.loca.xml`, `ExtraItems.loca.xml`, `Arcanizer.loca.xml` |
| Файлы в чужом моде | `Mods/REL_Full_Ancient_…/Localization/{English,Russian}/AncientJewelry.loca.xml`, `ExtraItems.loca.xml`, `Arcanizer.loca.xml` |
| Переопределённые строки | Отсутствующие `h3a2…4d37`, `hbb14…8201`; устаревшая `he90b…f471` |
| Базис | В английской локализации найдены 4 UID без русских строк: 2 пользовательские строки и 2 служебных комментария переводчику. Русское описание распылятора обещало один артефакт и случайные редкие ресурсы, тогда как актуальное английское требует 2 именных магических артефакта и выдаёт волшебную пыль |

Patch Relay добавляет описание украшения и реплику Жатвы Темнейшего, а описание распылятора приводит к актуальной механике Ancient Mega Pack. Два служебных английских комментария, начинающихся с `%%%`, намеренно не переводятся и в игру не добавляются.
